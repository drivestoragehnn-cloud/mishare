# انتقال سریع فایل (FastShare)

اپلیکیشن اندروید Material Design 3 برای انتقال فایل بین دو گوشی با **Wi-Fi Direct**
(سرعت واقعی، نه بلوتوث خام) — اتصال اولیه با QR کد یا بلوتوث.

## ساختار پروژه

```
shareit_clone/
├── .github/workflows/build-apk.yml   ← بیلد خودکار APK در فضای ابری گیت‌هاب (بدون نیاز به داکر/لینوکس)
├── build.py                          ← اسکریپت بیلد محلی (فقط لینوکس/WSL)
└── src/
    ├── main.py               ← اپ اصلی KivyMD - همه اسکرین‌ها (هوم، مجوزها، اتصال، ارسال، تاریخچه)
    ├── wifidirect.py          ← ارتباط با Android WifiP2pManager
    ├── bluetooth_manager.py   ← ارتباط با Android BluetoothAdapter
    ├── qr_utils.py            ← تولید/خواندن QR کد
    ├── qr_scan_screen.py      ← اسکرین اسکن QR با دوربین
    ├── transfer.py            ← انتقال فایل روی TCP با گزارش پیشرفت و سرعت
    └── buildozer.spec         ← تنظیمات بیلد اندروید
```

## 🏆 روش پیشنهادی برای ویندوز (بدون داکر، بدون WSL، بدون نصب چیزی)

چون Buildozer به‌طور بومی روی ویندوز کار نمی‌کنه و لازم نیست داکر یا WSL نصب کنی،
بهترین راه استفاده از **GitHub Actions** هست: بیلد کاملاً روی سرورهای گیت‌هاب (رایگان) انجام میشه.

### مراحل:

1. یک ریپوی جدید و **رایگان** روی [github.com](https://github.com) بساز (اگه اکانت نداری، ثبت‌نام کن)
2. پوشه `shareit_clone` رو به اون ریپو پوش کن. ساده‌ترین راه بدون خط فرمان:
   - وارد صفحه ریپو شو → دکمه **Add file → Upload files**
   - کل محتویات پوشه `shareit_clone` (شامل `.github` که فایل مخفیه، پس با ترمینال یا Git Desktop راحت‌تره) رو بکش و رها کن
   - (توصیه می‌کنم **GitHub Desktop** رو نصب کنی — یک برنامه گرافیکی ساده که پوش کردن رو با چند کلیک انجام میده، بدون نیاز به دستور ترمینال)
3. بعد از پوش شدن، برو به تب **Actions** توی همون ریپو — می‌بینی که ورک‌فلو "Build Android APK" خودش شروع به اجرا می‌کنه
4. صبر کن (اولین بار ۲۰-۴۰ دقیقه طول می‌کشه چون SDK/NDK دانلود میشه)
   - این ورک‌فلو مستقیم روی خود ران‌ر گیت‌هاب (اوبونتو) بیلد می‌کنه، بدون داکر تو دل داکر — پایدارتره
5. وقتی سبز شد ✅، روی همون اجرا کلیک کن → پایین صفحه بخش **Artifacts** رو باز کن → فایل `fastshare-apk` رو دانلود کن (یه zip حاوی APK)

بعد از این هر بار که کد رو عوض کنی و دوباره پوش کنی، APK جدید خودش ساخته میشه.

### مزیت این روش نسبت به بقیه:
- هیچی روی ویندوزت نصب نمیشه (نه داکر، نه WSL، نه لینوکس)
- کاملاً رایگانه (گیت‌هاب برای ریپوی عمومی/خصوصی شخصی، دقیقه‌های Actions رایگان کافی میده)
- هر بار خودکار بیلد میشه

## روش جایگزین (اگه لینوکس/WSL داری)

```bash
cd shareit_clone
python3 build.py
```

این اسکریپت Buildozer و وابستگی‌هاش رو نصب می‌کنه و مستقیم APK می‌گیره. **این روش روی ویندوز خام کار نمی‌کنه** — فقط لینوکس یا WSL2.

## معماری فنی

1. بلوتوث فقط برای **جفت‌شدن اولیه** (یا اسکن QR به‌جای بلوتوث)
2. بعد از اتصال، یک گروه **Wi-Fi Direct** بین دو گوشی تشکیل میشه
3. انتقال واقعی فایل روی **TCP از طریق Wi-Fi Direct** (تا ۲۰۰-۴۰۰ Mbps)
4. جریان اپ: هوم (ارسال/دریافت) → چک مجوزها (بلوتوث/موقعیت/وای‌فای) → انتخاب QR یا بلوتوث →
   (فقط مسیر ارسال) انتخاب نوع فایل (اپ/مدیا/فایل) → انتخاب فایل → صفحه انتقال زنده → تاریخچه

## معماری‌های پشتیبانی‌شده (یونیورسال)

فایل APK که ساخته میشه از قبل هر دو معماری اصلی گوشی‌های واقعی اندروید رو با هم داره
(`arm64-v8a` و `armeabi-v7a`) — یعنی همین یک فایل روی تقریباً همه گوشی‌های امروزی نصب و اجرا میشه،
نیازی به نسخه‌های جدا نیست.

## نکات مهم

- تست واقعی این اپ فقط روی گوشی اندروید ممکنه (pyjnius با Android API کار می‌کنه، نه دسکتاپ)
- `main.py` یک حالت شبیه‌سازی برای پیش‌نمایش UI روی دسکتاپ داره، ولی WiFi Direct/بلوتوث واقعی فقط روی گوشی کار می‌کنه
- اسکن QR از `pyzbar` استفاده می‌کنه؛ اگه روی گوشی مشکل نصب این کتابخونه پیش اومد، حالت "وارد کردن کد دستی" به‌عنوان جایگزین در کد وجود داره

## قدم بعدی پیشنهادی

- تکمیل هندشیک واقعی Wi-Fi Direct (گرفتن IP گروه بعد از اتصال بلوتوث/QR)
- رمزنگاری انتقال
- انتقال موازی چند فایل برای سرعت بیشتر
